# Default manual approval prompts

## Root Cause

This is a permission-engine default, not LLM behavior or a manual-mode harness failure. Both active engines install a broad `* -> allow` policy. Manual mode only turns off the application's automatic response to already-pending `ask` requests, so internal Bash and edit actions never create a prompt. External paths separately request `external_directory`, explaining why only those operations are currently shown for approval. Ordinary reads are explicitly allowed and should stay so.

## Goal

Make Bash and edit-family actions request approval by default across OpenCode. In the UI, Manual will display and wait for these requests, Auto will approve them, and Accept Edits will approve edits only. Noninteractive CLI runs will also require `--auto` to execute Bash/edit actions.

## Implementation

1. Update the V1 default agent permission policy in `packages/opencode/src/agent/agent.ts`:
   - Add `bash: "ask"` and `edit: "ask"` after the broad `*` allow rule.
   - Keep ordinary `read` rules unchanged.
2. Update the V2 built-in agent permission policy in `packages/core/src/plugin/agent.ts` with matching `bash` and `edit` `ask` rules after its broad allow rule.
3. Preserve rule ordering so plan-mode denial and later user/agent allow or deny overrides continue to take precedence.
4. Update focused V1 and V2 default-policy tests to assert `bash` and `edit` ask, read remains allowed, and explicit overrides still win. Add or update CLI coverage that default noninteractive runs reject the new asks while `--auto` accepts them.
5. Do not change `.opencode/opencode.jsonc`: this is a product default rather than a Forge-only configuration override.

## Verification

1. Run the focused V1 agent/permission/CLI tests from `packages/opencode` and V2 agent/permission/config tests from `packages/core`.
2. Run `bun typecheck` from each affected package.
3. In the UI, confirm Manual prompts for an internal file edit and workspace shell command, allows ordinary internal reads without prompting, Auto accepts both, and Accept Edits accepts edits while leaving Bash pending.
4. Confirm `opencode run` rejects a Bash/edit permission request by default and succeeds with `--auto`.
