## Plan Shape

Present the plan as Markdown with these sections, scaled to the size of the change:
- `# Title`: the actual change, with the phase or issue number when there is one.
- `## Context`: why the change is needed and the current behavior, citing files, symbols, and line numbers you verified. Say what deliberately does not change.
- `## Design`: how the pieces connect, with a small plain-text data-flow diagram for cross-component work, and where each responsibility lives.
- `## Changes`: one numbered `### N. path` subsection per file, with target symbols, signatures, exact error messages, constants, and short snippets where the shape matters.
- `## Tests`: test files and numbered cases with concrete inputs and expected results. Tests ship with the change.
- `## Verification`: commands with the directory they run from, then numbered manual scenarios with expected results.
- `## Out of scope`: excluded adjacent work and limitations.
