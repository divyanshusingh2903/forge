- Reads the page in a tab of the session's Browser panel as rendered right now, after JavaScript has run.
- Formats: `markdown` (default), `text`, `html`, or `interactive`.
- `interactive` lists actionable elements (links, buttons, inputs, …) as `[eN] role "name"` with state. Refs are valid until the page navigates; read again to get fresh refs. It needs the desktop Browser panel (no server fetch fallback).
- Reads the active tab unless `tabID` is given. Use `browser_navigate` first to load a page; its output lists the open tab IDs.
- For the other formats, when no Browser panel is attached (or the live read fails), the tab's URL is fetched by the server instead. The output's `source` line says which happened; a server fetch has no JavaScript execution and no browser cookies.
- Do NOT use it for general web fetching or documentation lookups; use `webfetch` for normal URLs.
